# 阅读页面设计 分析报告

> 任务编号：T-17
> 完成日期：2026-05-02
> 基于：docs/PROJECT_V2_PLAN.md

## 1. 背景与目标

佛教经文阅读器 v2.0 的核心页面是阅读页面，这是用户最常使用的功能入口。阅读体验的好坏直接决定了产品的成败。

本分析旨在：
- 调研主流阅读 App（微信读书、得到、掌阅）的阅读页面设计
- 基于可读性研究确定字体、字号、行间距、页边距等排版参数
- 设计适合佛教经文诵读场景的主题模式（日间/夜间/护眼）
- 确定翻页模式、目录导航、阅读进度等交互方案
- 为 v2.1 版本（阅读页面实现）提供明确的设计指导

## 2. 同类 App 阅读页对比

| 功能 | 微信读书 | 得到 | 掌阅 iReader | 本项目需求 |
|------|----------|------|--------------|------------|
| 字体选择 | 系统默认+付费字体（方正系列），支持宋体/黑体/楷体切换 | 系统默认，不可自定义字体 | 丰富字体库（方正、汉仪等），支持自定义导入 | 免费开源字体优先，宋体/楷体适合经文，支持梵文/藏文字体 |
| 字号调节 | 滑块调节，范围约 12px-28px | 滑块调节，范围约 13px-24px | 滑块调节，范围约 10px-30px | 滑块或步进按钮，14px-26px，默认 17px |
| 行间距 | 3 档（紧凑/标准/宽松），约 1.5x/1.7x/1.9x | 2 档（标准/宽松），约 1.6x/1.8x | 多档可调，支持自定义 | 3-4 档 + 滑块微调，1.6x-2.0x |
| 翻页模式 | 仿真翻页/上下滚动/无动画 | 上下滚动为主 | 仿真翻页/上下滚动/左右滑动 | 滚动优先（经文不分页），可选翻页 |
| 夜间模式 | 深色背景 + 浅色文字，非纯黑 | 深色背景 + 暖灰文字 | 多主题可选（深灰/深蓝/暖棕） | 暖深色背景，避免纯黑，保持温暖感 |
| 护眼模式 | 米黄色背景 + 深棕文字 | 暖色调背景 | 多种护眼配色（浅绿/米黄/浅棕） | 宣纸色/羊皮纸色，模拟纸质经书质感 |
| 目录导航 | 右侧滑出，显示章节列表，支持跳转 | 左侧滑出，大纲式导航 | 左侧/右侧滑出，支持章节和书签 | 左侧滑出，支持品/章/节多级导航 |
| 阅读进度 | 底部进度条 + 百分比显示 | 顶部进度条 + 章节信息 | 底部进度条 + 页码显示 | 顶部轻量进度指示，显示章节名 + 百分比 |
| 段落缩进 | 首行缩进 2 字符 | 无缩进，段间空行 | 可选首行缩进或段间距 | 经文不分段不缩进，注释可缩进 |

### 关键洞察

1. **字号 + 行距 > 字体选择**：多项研究表明，在长时间阅读场景下，排版参数（字号、行距）对舒适度的影响远大于字体本身。熟悉度效应（mere exposure effect）使用户对常用字体阅读速度更快。
2. **滚动优于翻页**：经文通常为连续文本，不分章节分页，滚动模式更符合"诵读"场景。微信读书已提供上下滚动模式，掌阅也支持。
3. **夜间模式非纯黑**：主流 App 均采用深灰/深棕色而非纯黑背景，因为纯黑背景上白色文字会产生"光晕效应"（halation），反而增加眼疲劳。
4. **护眼色偏暖**：米黄色（#F5F0E8）、浅棕色等暖色调比护眼绿更接近纸质书体验，也更契合佛教禅意风格。

## 3. 字体系统设计

### 3.1 中文字体栈

佛教经文阅读推荐使用**宋体**作为正文字体，原因：
- 宋体的横细竖粗笔画结构适合长时间阅读
- 传统印刷佛经多用宋体/楷体，用户有阅读习惯
- 宋体在较大字号下显示效果优雅

推荐的 CSS 字体栈（按优先级）：

```css
/* 正文默认字体栈 - 宋体优先 */
font-family:
  "Noto Serif SC",           /* Google 开源，覆盖全面 */
  "Source Han Serif SC",     /* Adobe 思源宋体 */
  "Songti SC",               /* macOS 宋体 */
  "SimSun",                  /* Windows 中易宋体 */
  "STSong",                  /* macOS 华文宋体 */
  "AR PL UMing CN",          /* Linux 文鼎宋体 */
  serif;                     /* 通用回退 */

/* 楷体备选 - 用于经文原文标注 */
font-family:
  "KaiTi",                   /* Windows 楷体 */
  "STKaiti",                 /* macOS 华文楷体 */
  "AR PL UKai CN",           /* Linux 文鼎楷体 */
  "Noto Serif SC",           /* 回退到宋体 */
  serif;

/* 无衬线体 - 用于 UI 文字、注释 */
font-family:
  "PingFang SC",             /* macOS 苹方 */
  "Microsoft YaHei",         /* Windows 微软雅黑 */
  "Noto Sans SC",            /* Google 开源 */
  "Source Han Sans SC",      /* Adobe 思源黑体 */
  sans-serif;
```

**字体加载策略**：
- 默认使用系统字体栈，无需下载字体
- 可选下载 Noto Serif SC 作为增强（WOFF2 格式，子集化后约 200KB）
- 霞鹜文楷（LXGW WenKai）可作为可选阅读字体，风格独特但需额外加载 ~5MB

### 3.2 梵文/藏文字体

佛教经文常含梵文（IAST 转写）和藏文标注，需要专门的字体支持：

```css
/* 梵文/天城体支持 */
@font-face {
  font-family: "Sanskrit";
  src: url("/fonts/NotoSansDevanagari-Regular.woff2") format("woff2");
  font-display: swap;
}

/* 藏文支持 */
@font-face {
  font-family: "Tibetan";
  src: url("/fonts/NotoSansTibetan-Regular.woff2") format("woff2");
  font-display: swap;
}
```

推荐字体（Google Noto 系列，开源免费）：

| 文字类型 | 字体 | 大小 | 说明 |
|----------|------|------|------|
| 梵文（天城体） | Noto Sans Devanagari | ~150KB | 覆盖 IAST 和天城体 |
| 藏文 | Noto Sans Tibetan | ~200KB | 完整藏文字符集 |
| 巴利文（罗马转写） | 使用正文字体 | - | IAST 转写用拉丁字母 |

**加载策略**：
- 梵文/藏文字体不预加载，仅在检测到经文包含对应 Unicode 范围时按需加载
- 使用 `font-display: swap` 避免阻塞渲染

### 3.3 字号调节范围

| 级别 | 字号 | 适用场景 |
|------|------|----------|
| 最小 | 14px | 研究者快速浏览 |
| 默认 | 17px | 日常诵读 |
| 推荐 | 18px-20px | 长时间阅读 |
| 最大 | 26px | 视力不佳用户 |

调节方式：
- **滑块**：连续调节，范围 14px-26px，步进 1px
- **快捷按钮**：小/中/大 三档快速切换
- 字号偏好持久化到 IndexedDB

## 4. 排版参数设计

| 参数 | 推荐值 | 范围 | 说明 |
|------|--------|------|------|
| 行间距（line-height） | 1.8 | 1.6-2.0 | 中文阅读最佳行高为字号的 1.6-1.8 倍，经文诵读可适当放宽至 1.8-2.0 |
| 段落间距（margin-bottom） | 1.5em | 1em-2em | 经文段落间留白，增强呼吸感 |
| 页边距（水平） | 16px（手机）/ 24px（平板）/ 48px（PC） | 响应式 | 手机端最小 16px 保证可读区域 |
| 页边距（垂直） | 24px | 16px-32px | 上下留白 |
| 每行字数 | 25-35 字 | - | 移动端最佳每行字符数，PC 端最大不超过 45 字 |
| 首行缩进 | 0（经文）/ 2em（注释） | - | 经文原文不缩进，注释/解说可缩进 |
| 字间距（letter-spacing） | 0.02em | 0-0.05em | 中文默认无需调整，可选微调增加呼吸感 |
| 文本对齐 | 两端对齐（text-align: justify） | 左对齐/两端对齐 | 两端对齐更适合经文排版 |

**研究依据**：
- 中文排版推荐 line-height: 1.7-1.8 作为起点（php.cn 技术文章），小于 1.5 容易粘连，大于 2.0 会割裂段落节奏
- 思源宋体书籍排版建议：Regular 字重配合 1.6-1.8 倍行高
- 每行 25-35 个中文字符是移动端最佳可读范围（参考微信读书/掌阅的实际渲染效果）
- 阅读舒适度优先级：亮度 > 字号 > 行距 > 字体

## 5. 主题模式设计

### 5.1 日间模式

模拟纸质经书质感，温暖不刺眼。

| 元素 | 配色值 | 说明 |
|------|--------|------|
| 背景色 | `#FAF8F3` | 米白色，接近宣纸色调 |
| 正文文字 | `#2C2C2C` | 深灰，非纯黑，减少对比度冲击 |
| 标题文字 | `#1A1A1A` | 更深灰，层级区分 |
| 注释文字 | `#6B6B6B` | 中灰，弱化 |
| 高亮术语 | `#8B4513` | 深棕色底 + 棕色文字，禅意感 |
| 分隔线 | `#E8E2D6` | 暖灰 |
| 链接/可点击 | `#A0522D` | 赭石色，传统中国色 |

### 5.2 夜间模式

暖深色背景，避免纯黑，保持温暖感。

| 元素 | 配色值 | 说明 |
|------|--------|------|
| 背景色 | `#1E1E1E` | 暖深灰，非纯黑（#000000） |
| 正文文字 | `#D4CFC7` | 暖米白，色温偏暖 |
| 标题文字 | `#E8E3DB` | 更亮的暖白 |
| 注释文字 | `#8A8578` | 暖中灰 |
| 高亮术语 | `#C8956C` | 暖棕高亮 |
| 分隔线 | `#333333` | 深灰分隔 |
| 链接/可点击 | `#B8860B` | 暗金色 |

**设计理由**：
- 纯黑背景（#000000）会导致白色文字产生"光晕效应"，增加眼疲劳
- 暖深灰（#1E1E1E）配暖米白文字（#D4CFC7）对比度适中（约 10:1），符合 WCAG AA 标准
- 整体色温偏暖，契合佛教禅意氛围

### 5.3 护眼模式

宣纸色/羊皮纸色，模拟传统纸质经书。

| 元素 | 配色值 | 说明 |
|------|--------|------|
| 背景色 | `#F5E6C8` | 宣纸色，暖黄偏棕 |
| 正文文字 | `#3D3229` | 深棕，墨色感 |
| 标题文字 | `#2A2018` | 更深棕 |
| 注释文字 | `#7A6B5D` | 中棕 |
| 高亮术语 | `#8B4513` | 马鞍棕 |
| 分隔线 | `#D4C4A8` | 浅棕黄 |
| 链接/可点击 | `#A0522D` | 赭石色 |

**切换方式**：
- 点击屏幕中央呼出工具栏，顶部显示三种主题模式图标
- 默认跟随系统（prefers-color-scheme），但可手动覆盖
- 主题偏好持久化到 IndexedDB

## 6. 交互设计

### 6.1 翻页 vs 滚动

**推荐方案：滚动模式为主，翻页模式可选**

| 维度 | 滚动模式 | 翻页模式 |
|------|----------|----------|
| 经文连续性 | 连续无断点，适合诵读 | 分页打断阅读流 |
| 定位精度 | 精确定位到字符 | 只能定位到页 |
| 阅读进度记忆 | 精确记录滚动位置 | 记录页码 |
| 查找经文 | 浏览器原生 Ctrl+F 可用 | 需要额外实现 |
| 移动端体验 | 自然滑动，符合习惯 | 仿真翻页动画耗性能 |
| 纸质书模拟 | 类似经折装/卷轴 | 类似线装书翻页 |

**决策理由**：
1. 佛教经文通常为连续文本，不分页更自然
2. 滚动模式下阅读进度可精确定位到字符位置
3. 微信读书已提供"上下滚动"模式，用户接受度高
4. 翻页模式可作为可选项保留（仿真翻页/左右滑动）
5. PC 端可考虑左右箭头翻页 + 滚轴滚动两种模式

**实现建议**：
- 默认滚动模式
- 设置页可切换"翻页模式"（仿真翻页 / 左右滑动 / 滚动）
- 不同模式独立记忆

### 6.3 阅读进度

**推荐方案：顶部轻量进度指示**

| 元素 | 显示内容 | 位置 |
|------|----------|------|
| 进度条 | 细线进度条，显示阅读百分比 | 顶部工具栏下方 |
| 章节名 | 当前章节名称 | 顶部工具栏中央 |
| 百分比 | 阅读进度百分比 | 底部状态栏（可选） |
| 已读时间 | 本次诵读时长 | 底部状态栏（可选） |

**显示策略**：
- 默认隐藏进度条，仅在以下场景显示：
  - 点击屏幕呼出工具栏时

- 底部状态栏可显示：章节名 | 进度百分比 | 已读时间
- 阅读进度自动保存（节流：每 30 秒或位置变化超过 10% 时保存）

## 7. 结论与建议

### 7.1 推荐的阅读页设计方案

| 项目 | 推荐方案 | 理由 |
|------|----------|------|
| 字体 | 宋体优先（Noto Serif SC > 思源宋体 > 系统宋体） | 适合长时间阅读，符合传统佛经印刷习惯 |
| 默认字号 | 17px，可调范围 14px-26px | 平衡可读性和信息密度 |
| 行间距 | 1.8 倍，可调范围 1.6-2.0 | 中文阅读最佳舒适度区间 |
| 页边距 | 手机 16px / 平板 24px / PC 48px | 响应式适配 |
| 翻页模式 | 滚动为主，翻页可选 | 经文连续文本更适合滚动 |
| 默认主题 | 日间模式（宣纸色 #FAF8F3） | 禅意/极简/温暖 |
| 夜间模式 | 暖深灰（#1E1E1E）+ 暖米白文字 | 非纯黑，减少光晕效应 |
| 护眼模式 | 宣纸色（#F5E6C8）+ 深棕文字 | 模拟纸质经书 |
| 目录导航 | 左侧滑出，多级章节 | 符合移动端操作习惯 |
| 阅读进度 | 顶部细线进度条，呼出时显示 | 不打扰阅读 |

### 7.2 设计原则

1. **不打扰**：阅读页面默认只显示经文正文，所有工具栏/状态栏点击后才出现
2. **可定制**：字体、字号、行距、主题都可调节，但提供合理的默认值
3. **禅意风格**：配色温暖、留白充足、无多余装饰，营造安静的阅读氛围
4. **响应式**：手机/平板/PC 三种布局自适应，每行字数控制在 25-45 字
5. **性能优先**：字体按需加载，阅读进度节流保存，避免不必要的渲染

### 7.3 差异化特色

相比通用阅读 App，佛教经文阅读器的独特之处：

| 特色 | 说明 |
|------|------|
| 术语高亮 | 佛教术语自动高亮，点击显示释义 |
| 拼音标注 | 特殊读音术语显示拼音（如"般若"标"bō rě"） |
| 梵文/藏文支持 | 内置 Noto Sans Devanagari/Tibetan 字体 |
| 功德统计 | 记录诵读次数、时长、连续天数 |
| 禅意配色 | 宣纸色、墨色、赭石色等中国传统色 |
| 不分页设计 | 经文连续滚动，类似经折装/卷轴 |

## 8. 对 v2.1 方案的影响

本分析结果对 v2.1（阅读页面实现）方案的具体影响：

1. **CSS 变量体系**：需要建立完整的 CSS 变量体系支持三种主题模式切换
2. **字体加载策略**：正文字体使用系统栈，梵文/藏文字体按需加载
3. **阅读状态管理**：Pinia reader store 需要存储：当前字号、行距、主题、目录展开状态
4. **滚动位置同步**：需要实现虚拟滚动或位置映射，将滚动位置映射到经文章节
5. **工具栏组件**：需要设计可显示/隐藏的顶部工具栏和底部状态栏
6. **目录侧栏组件**：左侧滑出式目录面板，支持多级章节和当前章节高亮
7. **响应式布局**：每行最大宽度限制（max-width: 65ch），居中显示
