### §1.2 的可验证替代证据
- 面板/弹窗均为 `position: fixed` 覆盖层（`components/common/BaseSheet.vue`、`ReaderSearch.vue` 等）——**不参与正文重排**，故「关闭面板 → nextTick → 定位」不落在动画期；

### §6.④ 的可验证替代证据
- `npm run typecheck`（`vue-tsc --noEmit`）作为 CI 门禁：模板中引用未声明的 prop/变量、或 `defineProps` 缺失导致类型不匹配，均会 **TS 报错**（编译期拦下，而非运行期白屏）。
- 可复验：在任一 `.vue` 中删除一个被模板使用的 `defineProps` 字段 → `npm run typecheck` 变红。

### ② §3.2 十条清洗正则：⑧、⑨ 曾**不可达（dead code）** —— **✅已修（T10b）**
- **T10 实测**：规则 ⑦ `（参阅[^）]*）` 与 ⑧ 起始锚点相同且**先行**；只要 ⑧ 模式成立（末尾必有 `）`），⑦ 必在同一位置命中并吞掉 `（参阅` 前缀 → ⑧ 永不触发；⑨ 对 ⑥ 同理。证据：穷举字母表 `（）'参阅甲［］` 的 ≤8 长度串，移除 ⑧ 或 ⑨ 后输出 **diffs = 0**。
- **T10b 修复**：按 **specific → general 重排**（⑧ 先于 ⑦、⑨ 先于 ⑥）——**恢复原意，不删规则**（删＝承认功能缺失）。现 `（参阅'智）慧'见）` → `''`（⑧ 整段清理），`甲［参阅'x］y'］乙` → `甲乙`（⑨ 整段清理）；无引号的 `（参阅x）` 仍由 ⑦ 清理。
- **测试改向**：原「现状锁定」用例已**改为断言应有行为**（锁定 bug 会把错误固化成规格）。反向验证：把顺序改回旧序 → 两条用例**必红**（实测）。

### ③ M7 词典搜索页：scope 写「四级匹配（含释义）+ debounce 300ms」 —— **⏸口径**

## 五、产出 5 说明：§2.⑥ 性能项 —— 选「行为断言」而非「时间断言」

- **选择**：**(a) 行为断言**（team-lead 倾向项）。
- **理由**：方案 §13 原写「重建 < 100ms」，但**时间断言在 CI 上极易 flaky**（机器负载/冷启动）；为「稳定」而放宽到必然通过的阈值 = **装饰性护栏**（与恒真断言同族，违反「做不到反向验证的断言一律视为装饰」硬规则）。
- **改为断言两个确定性不变量**（即「惰性 + memo」语义本身）：
  1. **惰性**——创建 highlighter 后、首次 `highlight` 前**不构建** Trie；
  2. **memo**——同词表引用只构建一次（同实例 computed 缓存 + 跨实例 WeakMap identity memo），**引用变化才重建**。
- **反向验证（必红）**：① 令 `getTrie` eager → 「惰性」用例红（实测）；② 移除 `trieMemo` WeakMap → 「WeakMap identity memo」用例红（实测）。→ 二者均非装饰。
