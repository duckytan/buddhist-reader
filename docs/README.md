# 项目文档

本目录包含项目的开发和维护文档。

## 文档列表

- **DEVELOPMENT_LOG.md** - 开发日志，记录每日进度和完成情况
- **DEVELOPMENT_GUIDE.md** - 详细开发指南，包含43个开发任务
- **CHECKLIST.md** - 开发检查清单，200+ 项检查点
- **ACCEPTANCE.md** - 验收标准和测试脚本
- **README.md** - 项目概述和快速开始指南
- **package.json** - 依赖配置（包含版本信息）

## 开发流程

1. 参考 **DEVELOPMENT_GUIDE.md** 了解开发任务
2. 按照 **CHECKLIST.md** 逐项检查完成情况
3. 在 **DEVELOPMENT_LOG.md** 记录每日进度
4. 使用 **ACCEPTANCE.md** 进行验收测试
