## 1. 项目概述

### 1.1 项目定位

般若佛经阅读器是一款**禅意极简风格**的佛教经文阅读与词典查询 Web 应用，专注于：

- **经文诵读**：提供流畅的中文经文阅读体验，支持诵读模式
- **词典高亮**：多词典词条实时高亮匹配，点击即可查看释义
- **用户笔记**：在阅读过程中记录个人理解和感悟
- **完全离线**：所有数据存储在浏览器 IndexedDB 中，无需后端

### 1.2 核心特性

| 特性 | 说明 |
|------|------|
| **禅意设计** | 宋体优先、暖色调宣纸背景、克制优雅的动画 |
| **多词典高亮** | 支持内置词典 + 用户上传 MDX/JSON/CSV 词典 |
| **流式释义** | 多词典并行查询，先返回先渲染，无需等待 |
| **完全离线** | IndexedDB 存储，PWA 支持，无网络也可使用 |
| **移动端优先** | 响应式设计，适配手机/平板/PC |

### 1.3 技术选型依据

经过 52 个调研任务的深度分析，核心技术栈选定如下：

| 层 | 技术 | 选型依据 |
|----|------|----------|
| **框架** | Vue 3 + Composition API | T-01：生态成熟、组件拆分灵活 |
| **构建** | Vite 5 | 原生 ESM、冷启动快、插件生态完善 |
| **UI** | Vant 4 | T-03：移动端优化、91% 组件覆盖 |
| **状态** | Pinia | T-01：TypeScript 友好、按需注册 |
| **存储** | IndexedDB + idb (~3KB) | T-04：容量大、10 万词条读写 < 5ms |
| **路由** | Vue Router 4 | 官方配套、history 模式 |
| **渲染** | markdown-it + DOMPurify | T-07/T-14：插件生态、SSR 兼容、XSS 防护 |
| **转换** | turndown | T-09：浏览器端 HTML→Markdown 唯一方案 |
| **词典** | mdict-js (v10.0.1 MIT) | T-06：支持 UTF-8/GBK/Big5、lookup 20K ops/sec |
| **压缩** | lzo-wasm | T-06：WASM 解压 250-400MB/s |
| **图标** | Lucide Icons | T-49：线性风格符合禅意，禁用 Emoji |

### 2.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **接口与实现分离** | Service 层定义 TypeScript 接口，IndexedDB 和未来 REST API 分别实现 |
| **大型数据不入库** | 章节内容、释义全文等大数据不放入 Pinia Store，由 Service 层按需加载 |
| **按需懒加载** | 词典索引按需加载，MDX 按大小分级处理，经书分块存储 |
| **纯前端优先** | 所有数据存储在 IndexedDB，预留后端 API 切换能力 |
| **安全四层防护** | 文件验证 → MDX 扫描 → DOMPurify 净化 → CSP 拦截 |

### 4.3 Trie 引擎设计

#### Trie 数据结构

```javascript
// engine/trie/TrieNode.js

export class TrieNode {
  constructor() {
    this.children = new Map();   // char -> TrieNode
    this.isEnd = false;          // 是否是词条结尾
    this.dictIds = new Set();    // 包含此词条的词典 ID
  }
}
```

#### Trie 构建器（Worker 中使用）

```javascript
// engine/trie/TrieBuilder.js

export class TrieBuilder {
  constructor() {
    this.root = new TrieNode();
  }

  insert(term, dictId) {
    let node = this.root;
    for (const char of term) {
      if (!node.children.has(char)) {
        node.children.set(char, new TrieNode());
      }
      node = node.children.get(char);
    }
    node.isEnd = true;
    node.dictIds.add(dictId);
  }

  // 批量插入（用于 Worker 构建）
  insertBatch(terms) {
    for (const { term, dictId } of terms) {
      this.insert(term, dictId);
    }
  }

  // 序列化（用于 Worker → 主线程传输）
  serialize() {
    // 将 Trie 转换为并行数组结构
    const chars = [];
    const isEnds = [];
    const dictIdsList = [];
    const childIndices = [];
    // BFS 遍历序列化...
    return { chars, isEnds, dictIdsList, childIndices };
  }

  destroy() {
    this.root = null;  // 释放内存
  }
}
```

#### Trie 匹配器（主线程中使用）

```javascript
// engine/trie/TrieMatcher.js

export class TrieMatcher {
  constructor(serializedData) {
    this.deserialize(serializedData);
  }

  // 贪心长词优先匹配
  match(text, startIdx, maxLen = 20) {
    let node = this.root;
    let lastEnd = -1;
    let lastDictIds = new Set();

    for (let i = startIdx; i < Math.min(startIdx + maxLen, text.length); i++) {
      const char = text[i];
      if (!node.children.has(char)) break;

      node = node.children.get(char);
      if (node.isEnd) {
        lastEnd = i;
        lastDictIds = new Set(node.dictIds);
      }
    }

    if (lastEnd >= 0) {
      return {
        term: text.slice(startIdx, lastEnd + 1),
        endIdx: lastEnd,
        dictIds: Array.from(lastDictIds)
      };
    }
    return null;
  }
}
```

### 4.4 高亮渲染引擎

```javascript
// engine/highlighter.js

import { TrieMatcher } from './trie/TrieMatcher.js';

export class Highlighter {
  constructor(matcher) {
    this.matcher = matcher;
  }

  // 对经文内容进行高亮处理
  highlight(content, activeDictIds) {
    const segments = [];
    let idx = 0;

    while (idx < content.length) {
      const match = this.matcher.match(content, idx);

      if (match && this.hasActiveDict(match.dictIds, activeDictIds)) {
        // 添加高亮段
        segments.push({
          type: 'highlight',
          term: match.term,
          dictIds: match.dictIds,
          text: match.term
        });
        idx = match.endIdx + 1;
      } else {
        // 添加普通文本段
        segments.push({
          type: 'text',
          text: content[idx]
        });
        idx++;
      }
    }

    return this.renderSegments(segments);
  }

  // 渲染为 HTML 字符串
  renderSegments(segments) {
    let html = '';
    for (const seg of segments) {
      if (seg.type === 'highlight') {
        const color = this.getHighlightColor(seg.dictIds[0]);
        html += `<span class="highlight" data-term="${seg.term}" data-dict-ids="${seg.dictIds.join(',')}" style="background:${color}">${seg.text}</span>`;
      } else {
        html += seg.text;
      }
    }
    return html;
  }

  hasActiveDict(dictIds, activeDictIds) {
    return dictIds.some(id => activeDictIds.includes(id));
  }

  getHighlightColor(dictId) {
    const colors = ['#FFF3CD', '#D1ECF1', '#D4EDDA', '#E2D5F1'];
    return colors[dictId % colors.length];
  }
}
```
