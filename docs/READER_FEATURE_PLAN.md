## 2. 核心阅读功能

### 2.1 阅读进度记录与恢复 ⭐⭐⭐⭐⭐

#### 功能描述
- **自动保存阅读位置**：滚动时自动记录滚动位置百分比
- **上次阅读提示**：打开经文时显示"继续阅读上次位置"
- **进度条可视化**：顶部显示阅读进度条
- **阅读时间统计**：记录累计阅读时长
- **断点续读**：关闭后再打开自动跳转上次位置

#### 技术实现
```javascript
// stores/progress.js 扩展
const sutraProgress = ref({
  'xin-jing': {
    scrollPercent: 0.35,  // 35%
    lastReadTime: '2026-04-26T09:30:00',
    totalReadTime: 3600,  // 秒
    chapterIndex: 0
  }
})

// 计算属性
const getProgress = (sutraId) => sutraProgress.value[sutraId]?.scrollPercent || 0
const setProgress = (sutraId, percent) => {
  sutraProgress.value[sutraId].scrollPercent = percent
  saveToStorage()
}
```

```

│ ← 般若波罗蜜多心经              35% │ ← 进度条
├─────────────────────────────────────┤
│                                     │

│   ──────────────────────────        │
│   继续阅读：上次读到此处            │ ← 提示条
│                                     │
└─────────────────────────────────────┘
```

### 3.2 经文搜索功能 ⭐⭐⭐⭐

#### 功能描述
- **全文搜索**：在当前经文中搜索关键词
- **搜索高亮**：高亮所有匹配结果
- **搜索导航**：上一个/下一个匹配项
- **搜索历史**：保存搜索历史
- **搜索建议**：输入时提示常见词汇

#### 技术实现
```javascript
// utils/search.js
const searchInSutra = (sutraId, keyword) => {
  const sutra = getSutraById(sutraId)
  const content = sutra.chapters.flatMap(ch => ch.content).join('\n')

  const results = []
  let index = 0
  while ((index = content.indexOf(keyword, index)) !== -1) {
    results.push({
      index,
      text: content.substring(
        Math.max(0, index - 20),
        Math.min(content.length, index + keyword.length + 20)
      ),
      chapter: findChapterByIndex(sutra, index)
    })
    index += keyword.length
  }

  return results
}
```
