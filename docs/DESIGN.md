## 一、视觉主题与氛围 🎨

### 设计哲学

般若佛经阅读器是一个专注佛教经文诵读的阅读工具。我们的设计目标是创造一个**让心静下来**的数字空间——如同进入古刹禅堂，万籁俱寂，唯有经声佛号。

### 核心原则

| 原则 | 说明 | 实现方式 |
|------|------|----------|
| **禅意** | 极简、克制、无干扰 | 纯色背景、少装饰、无装饰性元素 |
| **留白** | 呼吸空间、视觉停顿 | 1.8 倍行高、宽松间距、内容居中 |
| **专注** | 功能让位于体验 | 隐藏非必要 UI、沉浸式阅读、自动隐藏导航 |
| **温暖** | 不冰冷、不机械 | 金黄高亮、暖色点缀、人文气息 |

### 视觉关键词

```
静谧 · 克制 · 专注 · 温暖 · 素雅
```

### 设计反模式（DON'T）

❌ 鲜艳刺眼的颜色
❌ 复杂的装饰图案
❌ 过小的间距和拥挤的布局
❌ 自动播放的动画和音效
❌ 任何分散注意力的元素

## 二、色彩系统与角色 🎨

### 主色调

| 颜色 | 色值 | 使用场景 | 语义 |
|------|------|----------|------|
| **赤褐色** | `#FF6B35` | 主按钮/高亮下划线/开关激活 | 主要操作、强调、佛系温暖 |
| **金黄** | `#FFF3CD` | 词典高亮背景 (日间) | 知识/智慧/佛光 |
| **深灰** | `#4A4A4A` | 词典高亮背景 (夜间) | 夜晚禅堂/克制 |

### 基础色调

| 用途 | 日间 | 夜间 |
|------|------|------|
| **页面背景** | `#F5F5F5` (浅灰) | `#1A1A1A` (深空灰) |
| **卡片背景** | `#FFFFFF` (纯白) | `#2A2A2A` (禅堂灰) |
| **主要文字** | `#333333` (墨黑) | `#CCCCCC` (月光灰) |
| **次要文字** | `#666666` (中灰) | `#999999` (淡月灰) |
| **辅助文字** | `#999999` (淡灰) | `#666666` (深月灰) |
| **边框/分割线** | `#EEEEEE` (极淡灰) | `#333333` (深禅灰) |

### 功能色

| 用途 | 色值 | 使用场景 |
|------|------|----------|
| **成功/完成** | `#4CAF50` | 进度条 100%、完成状态 |
| **进度/强调** | `linear-gradient(90deg, #FF6B35, #FF8C5A)` | 阅读进度条、渐变按钮 |
| **警告/注意** | `#FF9800` | 低电量、网络异常 (慎用) |
| **错误/删除** | `#e74c3c` | 删除按钮 (极慎用) |

### 语义角色

```css

  --primary-gradient: linear-gradient(135deg, #FF6B35, #FF8C5A);
  --highlight-bg: #FFF3CD;
  
  /* 文字色 */
  --text-primary: #333333;
  --text-secondary: #666666;
  --text-tertiary: #999999;
  
  /* 背景色 */
  --bg-page: #F5F5F5;
  --bg-card: #FFFFFF;
  --bg-component: #FAFAFA;
  
  /* 边框/分割 */
  --border-color: #EEEEEE;
  
  /* 功能色 */
  --success-color: #4CAF50;
  --danger-color: #e74c3c;
}
```

| 用途 | 中文 | 英文 | 梵文 |

## 五、布局原则 📐

### 间距标尺

使用 **8px 基准** 的间距系统：

| 间距 | 用途 |
|------|------|
| `4px` | 极小间距 (标签内部) |
| `8px` | 小组件间距 (图标与文字) |
| `12px` | 常规间距 (列表项/按钮) |
| `16px` | 标准间距 (页面边距/卡片) |
| `20px` | 大间距 (章节间隔) |
| `24px` | 超大间距 (分组间隔) |
| `32px` | 页面级间距 (section 间隔) |

### 网格系统

**移动端 (≤ 600px)**:
- 单列布局
- 页面边距 16px
- 卡片全宽

**平板端 (768px)**:
- 2-3 列网格
- 页面边距 24px
- 卡片间距 20px

**桌面端 (1200px+)**:
- 4 列网格 + 侧边栏
- 页面边距 32px
- 居中布局 (max-width: 1200px)

### 留白哲学

> "留白不是空洞，而是呼吸的空间。"

- 内容区域宽度控制在 600px 以内
- 段落之间 24px 间距
- 行高 1.8 倍，让视线自然流动
- 页面底部保留 80px 呼吸区

## 七、Do's and Don'ts ⚠️

### DO ✅

- 使用留白创造呼吸空间
- 保持一致的间距 (8/16/24px)
- 经文阅读优先，功能次之
- 夜间模式降低对比度 (不用纯黑)
- 使用渐变增加人文温度
- 高亮色克制使用 (仅词典)

### DON'T ❌

- 使用超过 3 种主色
- 卡片圆角不统一 (有的 4px 有的 12px)
- 自动播放动画/音效
- 纯黑背景 (#000000) 刺眼
- 过多装饰性元素
- 让 UI 元素分散诵读注意力
