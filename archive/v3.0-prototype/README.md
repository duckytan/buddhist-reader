# 般若佛经阅读器 - 响应式原型

> 禅意极简风格的佛经阅读与词典查询 Web 应用原型

## 预览地址

**https://5173-7b99689ba9fd24f5.monkeycode-ai.online**

## 页面概览

| 页面 | 路由 | 说明 |
|------|------|------|
| **书架** | `/bookshelf` | 经书列表，支持分类筛选和搜索 |
| **阅读** | `/reader` | 金刚经全文，高亮词可点击，目录弹出 |
| **词典** | `/dict` | 词典管理，支持导入和颜色配置 |
| **设置** | `/settings` | 主题切换、字体大小、行高实时调节 |

## 响应式布局

| 设备 | 断点 | 导航方式 | 布局特点 |
|------|------|----------|----------|
| **桌面** | >= 1024px | 左侧边栏 | 书架 3-4 列，词典侧边栏，设置页带预览面板 |
| **平板** | 768-1023px | 汉堡菜单 + 底部导航 | 书架 2 列，词典折叠面板，底部 Tab 切换 |
| **手机** | < 768px | 底部导航 | 单列布局，弹窗/抽屉式交互，44px 触摸目标 |

## 设计系统

### 核心理念

**界面退让，让经文内容成为主角。**

### 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 强调色 | `#8b7355` | 檀木色 — 唯一的交互色 |
| 画布白 | `#ffffff` | 页面主背景 |
| 宣纸色 | `#f8f7f4` | 区域背景，微暖米白 |
| 墨色 | `#2c2c2c` | 正文主色，近黑非纯黑 |
| 淡墨 | `#6b6b6b` | 次要文字 |
| 细线 | `#e8e6e1` | 边框、分隔线 |

### 暗色模式

| 用途 | 色值 |
|------|------|
| 画布暗 | `#1a1a1a` |
| 表面 1 | `#242424` |
| 表面 2 | `#2e2e2e` |
| 墨暗 | `#e0e0e0` |

### 排版

| 用途 | 大小 | 字重 | 行高 |
|------|------|------|------|
| 页面标题 | 32px | 600 | 1.25 |
| 卡片标题 | 18px | 600 | - |
| 正文 | 17px | 400 | 1.65 |
| 辅助文字 | 13px | 400 | - |

### 圆角

| 类型 | 值 | 用途 |
|------|------|------|
| 容器 | 8px | 卡片、面板、输入框 |
| 交互 | 9999px | 按钮、标签、开关 |

### 高亮分类

| 分类 | 背景色 | 文字色 |
|------|--------|--------|
| 智慧 | `#e8f5e9` | `#2e7d32` |
| 慈悲 | `#e3f2fd` | `#1565c0` |
| 禅定 | `#f3e5f5` | `#7b1fa2` |
| 仪轨 | `#fff3e0` | `#e65100` |

## 技术栈

- **框架**: Vue 3 (Composition API)
- **构建**: Vite 5
- **UI 组件**: Vant 4
- **路由**: Vue Router 4
- **图标**: 内联 SVG

## 本地开发

```bash
cd prototype
npm install
npm run dev
```

访问 `http://localhost:5173`

## 项目结构

```
prototype/
├── src/
│   ├── App.vue              # 根组件 + 布局 + 导航
│   ├── main.js              # Vue 应用入口

```
