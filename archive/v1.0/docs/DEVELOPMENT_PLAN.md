## 一、项目概述

### 1.1 项目定位

**般若佛经阅读器**是一款专注佛教经文诵读的跨平台阅读工具，提供读音纠正、词典高亮、TTS 朗读、功德统计等核心功能。

**目标用户**：佛教修行者、佛学爱好者、研究者

**核心理念**：简单、专注、不打扰

### 1.2 技术选型

| 类别 | 技术 | 版本 |
|------|------|------|
| 框架 | Vue 3 | ^3.4.0 |
| 构建工具 | Vite | ^5.2.0 |
| UI 组件 | Vant 4 | ^4.8.0 |
| 路由 | Vue Router | ^4.3.0 |
| 状态管理 | Pinia | ^2.1.7 |
| 语言 | JavaScript | ES6+ |
| 部署 | Vercel | 最新 |

### 1.3 支持平台

- ✅ **H5 Web**（优先）- PC/平板/手机响应式
- ⬜ **微信小程序**（二期）- 流量入口
- ⬜ **iOS App**（三期）- 深度用户
- ⬜ **Android App**（三期）- 深度用户

## 五、风险与应对

### 技术风险

| 风险 | 概率 | 影响 | 应对方案 |
|------|------|------|---------|
| Trie 树性能问题 | 低 | 中 | 分页加载、Web Worker |
| 大词典加载慢 | 中 | 中 | 按需下载、IndexedDB |
| TTS 兼容性 | 低 | 低 | 多引擎备选 |
| 响应式布局复杂 | 中 | 低 | 使用 CSS Grid/Flexbox |

### 进度风险

| 风险 | 概率 | 影响 | 应对方案 |
|------|------|------|---------|
| 词典数据整理耗时 | 高 | 中 | 先做核心 50 条，后续扩展 |
| 功能范围蔓延 | 中 | 高 | 严格按优先级执行 |
| 测试不充分 | 中 | 高 | 预留充足测试时间 |
