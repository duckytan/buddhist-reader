# 禅意 UI/UX 设计语言 报告

> 任务编号：T-42
> 完成日期：2026-05-02

## 1. 背景与目标

般若佛经阅读器 v2.0 需要定义一套完整的"禅意"视觉设计语言，这是产品的核心差异化特色。不同于通用阅读 App（微信读书、得到等）的现代化商业风格，也不同于部分佛经 App 的过度装饰化倾向，本项目追求"极简、克制、温暖"的禅宗美学——让用户在打开 App 的瞬间就能感受到安静与专注。

本设计语言文档覆盖以下层面：
- 核心设计原则与关键词
- 色彩系统（主色、辅助色、语义色、暗色模式）
- 字体系统（中文、梵文/藏文）
- 间距与布局系统
- 动画与过渡效果
- 图标风格
- 同类 App 对比分析
- 对 v2.1 及后续版本的具体影响

## 2. 禅意设计原则

### 2.1 核心原则

| 原则 | 描述 | 设计准则 |
|------|------|----------|
| **极简（Kanso）** | 去除一切不必要的装饰，只保留核心内容 | 无多余边框、无渐变背景、无复杂阴影、无装饰性分割线 |
| **留白（Ma）** | 用空间创造呼吸感，让文字成为视觉焦点 | 充足的页边距、段落间距、组件间距，宁可多留不可少留 |
| **温暖（On）** | 所有色彩都带有暖色调，避免冷色和纯黑纯白 | 背景偏米白/米黄，文字偏深灰/深棕，非纯黑 #000000 非纯白 #FFFFFF |
| **自然（Shizen）** | 模拟纸质经书的质感，而非电子屏幕感 | 宣纸色背景、墨色文字、柔和的圆角、无锐利边缘 |
| **克制（Enso）** | 动画和交互反馈适度收敛，不打扰阅读 | 过渡时长 200-300ms，缓动曲线用 ease-out，避免弹跳和弹性动画 |

### 2.2 设计关键词

**静 · 简 · 暖 · 净 · 柔**

- **静**：安静的阅读环境，界面不抢内容风头
- **简**：功能入口清晰但不喧闹，操作步骤最少化
- **暖**：所有颜色带有暖色调，营造安心感
- **净**：界面无多余元素，信息层级分明
- **柔**：圆角、柔和阴影、缓动动画，无尖锐感

## 3. 色彩系统

### 3.1 主色

禅意主色调源自中国传统色彩体系，以大地色系为核心，传达沉稳、内敛的气质。

| 色名 | 色值 | 用途 | 说明 |
|------|------|------|------|
| **墨色** | `#2C2C2C` | 正文文字 | 非纯黑的深灰，减少对比度冲击 |
| **宣纸白** | `#FAF8F3` | 日间背景 | 接近传统宣纸的米白色调 |
| **赭石** | `#A0522D` | 可点击元素、链接、主按钮 | 中国传统色，温暖而不张扬 |
| **赭石深** | `#8B4513` | 术语高亮底色、强调文字 | 更深的赭石色，禅意浓厚 |
| **墨深** | `#1A1A1A` | 标题文字 | 比正文更深一级的灰 |

> **与 v1.0 的区别**：v1.0 使用 `#FF6B35`（赤褐色）作为主色，过于鲜艳活泼，不符合禅意"克制"原则。v2.0 将主色降饱和度，改用赭石色 `#A0522D`，更加沉稳内敛。

### 3.2 辅助色

辅助色用于信息层级区分和组件变体。

| 色名 | 色值 | 用途 |
|------|------|------|
| **浅灰** | `#F0EDE8` | 卡片背景、分割线背景 |
| **暖灰** | `#E8E2D6` | 分隔线、边框 |
| **中灰** | `#6B6B6B` | 注释文字、次要信息 |
| **浅棕** | `#D4C4A8` | 护眼模式分隔线 |
| **米黄** | `#FFF3CD` | 术语高亮背景（日间） |
| **金棕** | `#C8956C` | 术语高亮背景（夜间） |

### 3.3 语义色

语义色保持低饱和度，避免破坏整体禅意氛围。

| 类型 | 色值 | 用途 | 说明 |
|------|------|------|------|
| **成功** | `#5A8F5A` | 已完成、导入成功 | 低饱和绿色，不刺眼 |
| **警告** | `#C4913A` | 词典重复、格式问题 | 暖调琥珀色 |
| **错误** | `#B85C5C` | 加载失败、删除确认 | 低饱和红色，非鲜艳红 |
| **信息** | `#6B8FA3` | 提示、说明文字 | 低饱和蓝灰，偏暖 |

> 所有语义色的饱和度均控制在 30-50% 范围内，避免使用 Material Design 标准色（如 #4CAF50、#F44336）等过于鲜亮的颜色。

### 3.4 暗色模式

暗色模式采用暖深灰而非纯黑，配暖米白文字，整体色温偏暖。

| 元素 | 日间模式 | 夜间模式 | 护眼模式 |
|------|----------|----------|----------|
| **页面背景** | `#FAF8F3` | `#1E1E1E` | `#F5E6C8` |
| **卡片背景** | `#FFFFFF` | `#2A2825` | `#FAF0E0` |
| **正文文字** | `#2C2C2C` | `#D4CFC7` | `#3D3229` |
| **标题文字** | `#1A1A1A` | `#E8E3DB` | `#2A2018` |
| **注释文字** | `#6B6B6B` | `#8A8578` | `#7A6B5D` |
| **分隔线** | `#E8E2D6` | `#333333` | `#D4C4A8` |
| **术语高亮** | `#FFF3CD` 底 + `#8B4513` 字 | `#4A4035` 底 + `#C8956C` 字 | `#E8D5B5` 底 + `#8B4513` 字 |
| **可点击/链接** | `#A0522D` | `#B8860B` | `#A0522D` |
| **阴影** | `rgba(0,0,0,0.06)` | `rgba(0,0,0,0.3)` | `rgba(0,0,0,0.08)` |

**夜间模式设计理由**：
- 纯黑背景（#000000）+ 白色文字会产生"光晕效应"（halation），反而增加眼疲劳
- `#1E1E1E` 是暖深灰，色温约 3000K，配 `#D4CFC7` 暖米白文字，对比度约 10:1，符合 WCAG AA 标准
- 夜间卡片背景 `#2A2825` 比页面背景略亮，形成微弱层级
- 夜间可点击色从日间的赭石色变为暗金色 `#B8860B`，在深色背景下更醒目

## 4. 字体系统

### 4.1 中文字体栈

佛教经文阅读以**宋体**为正文首选字体，楷体作为辅助字体用于经文原文标注，无衬线体用于 UI 界面文字。

**正文默认字体栈（宋体优先）**：

```css
--zen-font-serif:
  "Noto Serif SC",           /* Google 开源，覆盖最全面 */
  "Source Han Serif SC",     /* Adobe 思源宋体 */
  "Songti SC",               /* macOS 宋体 */
  "SimSun",                  /* Windows 中易宋体 */
  "STSong",                  /* macOS 华文宋体 */
  "AR PL UMing CN",          /* Linux 文鼎宋体 */
  serif;                     /* 通用回退 */
```

**楷体（经文原文/注释标注）**：

```css
--zen-font-kai:
  "KaiTi",                   /* Windows 楷体 */
  "STKaiti",                 /* macOS 华文楷体 */
  "AR PL UKai CN",           /* Linux 文鼎楷体 */
  "Noto Serif SC",           /* 回退到宋体 */
  serif;
```

**无衬线体（UI 文字、按钮、导航）**：

```css
--zen-font-sans:
  "PingFang SC",             /* macOS 苹方 */
  "Microsoft YaHei",         /* Windows 微软雅黑 */
  "Noto Sans SC",            /* Google 开源 */
  "Source Han Sans SC",      /* Adobe 思源黑体 */
  sans-serif;
```

**字号调节范围**：

| 级别 | 字号 | 适用场景 |
|------|------|----------|
| 最小 | 14px | 研究者快速浏览 |
| 默认 | 17px | 日常诵读 |
| 推荐 | 18px-20px | 长时间阅读 |
| 最大 | 26px | 视力不佳用户 |

**行高**：

| 参数 | 值 | 说明 |
|------|-----|------|
| 默认行高 | 1.8 | 中文阅读最佳舒适度 |
| 可调范围 | 1.6-2.0 | 紧凑到宽松 |
| 标题行高 | 1.4 | 紧凑但不拥挤 |
| 段落间距 | 1.5em | 经文段间留白 |

### 4.2 梵文/藏文字体

| 文字类型 | 字体 | 大小 | 加载策略 |
|----------|------|------|----------|
| 梵文（天城体） | Noto Sans Devanagari | ~150KB | 按需加载，font-display: swap |
| 藏文 | Noto Sans Tibetan | ~200KB | 按需加载，font-display: swap |
| 巴利文（罗马转写） | 使用正文字体 | - | 无需额外字体 |

```css
--zen-font-devanagari:
  "Noto Sans Devanagari",
  "ITF Devanagari",
  "Mangal",
  sans-serif;

--zen-font-tibetan:
  "Noto Sans Tibetan",
  "Microsoft Himalaya",
  sans-serif;
```

**加载策略**：梵文/藏文字体不预加载，仅在检测到经文包含对应 Unicode 范围时按需加载，使用 `font-display: swap` 避免阻塞渲染。

## 5. 间距系统

采用 **4px 基准间距系统**，所有间距值为 4 的倍数，确保视觉节奏的一致性和精确性。

| Token | 值 | 用途 |
|-------|-----|------|
| `--zen-space-1` | 4px | 图标与文字间距、紧凑内边距 |
| `--zen-space-2` | 8px | 按钮内边距、表单元素间距 |
| `--zen-space-3` | 12px | 卡片内边距（小）、列表项间距 |
| `--zen-space-4` | 16px | 卡片内边距（标准）、页面水平边距（手机） |
| `--zen-space-5` | 20px | 组件间距 |
| `--zen-space-6` | 24px | 段落间距、页面水平边距（平板） |
| `--zen-space-8` | 32px | 区块间距 |
| `--zen-space-10` | 40px | 页面水平边距（PC）、大区块间距 |
| `--zen-space-12` | 48px | 页面垂直边距、标题与内容间距 |
| `--zen-space-16` | 64px | 页面级留白 |

**响应式页边距**：

```css
/* 手机 */
.page-padding { padding: var(--zen-space-6) var(--zen-space-4); }

/* 平板 */
@media (min-width: 768px) {
  .page-padding { padding: var(--zen-space-8) var(--zen-space-6); }
}

/* PC */
@media (min-width: 1024px) {
  .page-padding { padding: var(--zen-space-10) var(--zen-space-10); }
}
```

## 6. 动画和过渡效果

禅意设计强调"克制"，动画存在的目的是引导注意力而非炫技。

### 6.1 时长标准

| 类型 | 时长 | 缓动曲线 | 用途 |
|------|------|----------|------|
| **微交互** | 150ms | `ease-out` | 按钮 hover、checkbox 切换 |
| **标准过渡** | 250ms | `ease-out` | 弹窗出现/消失、面板展开 |
| **页面过渡** | 300ms | `ease-out` | 页面切换、路由跳转 |
| **进度指示** | 200ms | `linear` | 进度条更新 |

### 6.2 CSS 变量

```css
:root {
  --zen-transition-fast: 150ms ease-out;
  --zen-transition-base: 250ms ease-out;
  --zen-transition-slow: 300ms ease-out;
  --zen-transition-linear: 200ms linear;
}
```

### 6.3 触发条件与行为规范

| 交互 | 动画效果 | 说明 |
|------|----------|------|
| 侧滑面板展开 | 从边缘平滑滑入，带 20% 遮罩渐显 | 不阻挡用户看到背后的内容 |
| 词典弹窗 | 从点击位置淡入 + 轻微缩放（0.95 → 1.0） | 自然出现感，无突兀跳动 |
| 主题切换 | 背景色 400ms 渐变过渡 | 平滑的颜色变化，避免闪烁 |
| 术语高亮 | 背景色 150ms 渐变 | 点击时短暂加深底色 |
| 滚动进度条 | 200ms 线性宽度变化 | 仅在快速滚动时临时显示 |
| 加载状态 | 无旋转动画，使用淡入淡出的骨架屏 | 避免喧闹的 loading 旋转 |

### 6.4 禁止的动画

- 弹跳（bounce）效果
- 弹性（spring）动画
- 3D 翻转
- 闪烁、脉冲效果
- 长时间循环动画（超过 1s）
- 自动播放的装饰性动画

## 7. 图标风格

### 7.1 风格定位

采用**线性图标（Outline Icons）**，线条宽度 1.5-2px，圆角端点，风格简约克制。

| 属性 | 值 | 说明 |
|------|-----|------|
| 风格 | 线性描边（Outline） | 非面性填充，更轻盈 |
| 线条宽度 | 1.5px（移动端）/ 2px（PC） | 与禅意设计的"细"感一致 |
| 端点 | 圆头（round） | 避免尖锐感 |
| 拐角 | 圆角（round join） | 柔和过渡 |
| 尺寸 | 20px / 24px / 28px | 标准三级尺寸 |

### 7.2 推荐图标库

| 图标库 | 特点 | 是否推荐 |
|--------|------|----------|
| **Lucide Icons** | 线性、一致性强、开源 MIT | 首选 |
| **Heroicons (Outline)** | 简洁线性、Tailwind 生态 | 备选 |
| **Remix Icon** | 风格统一、开源 | 备选 |
| Material Icons | 面性为主，风格偏商业 | 不推荐 |
| FontAwesome | 风格混杂，偏厚重 | 不推荐 |

### 7.3 图标语义映射

| 功能 | 图标 | 说明 |
|------|------|------|
| 目录 | `menu` / `list` | 章节导航 |
| 设置 | `settings` | 设置页面 |
| 字号调节 | `type` | 阅读设置 |
| 主题切换 | `sun` / `moon` | 日/夜间模式 |
| 书签 | `bookmark` | 添加书签 |
| 搜索 | `search` | 搜索经文 |
| 返回 | `chevron-left` | 返回上一页 |
| 关闭 | `x` | 关闭弹窗/面板 |
| 词典 | `book-open` | 词典管理 |
| 统计 | `bar-chart-3` | 功德统计 |

### 7.4 禁止使用 Emoji 作为功能图标

v1.0 中使用 Emoji（`📖`、`📚`、`🔍`、`⚙️`）作为图标，这在禅意设计中是不合适的：
- Emoji 色彩过于丰富，破坏极简氛围
- 跨平台渲染不一致
- 缺乏设计一致性

v2.0 应全部替换为 SVG 线性图标。

| **得到** | 极简学术 | 上下滚动为主，大纲式导航 | 简洁的阅读工具栏、知识卡片设计 | 非禅意风格，偏知识付费 |

### 关键洞察

1. **禅意设计的空白区域**：大多数佛经 App 要么过于简单（缺乏设计感），要么过于装饰化（莲花背景、金色边框等）。"极简禅意"在佛经阅读领域仍然是一个未被充分探索的设计方向。
2. **功能与克制的平衡**：功能丰富的 App（大乘佛经、大藏经）往往界面复杂；简洁的 App（地藏经卷下）又缺乏设计特色。本项目需要在功能完整性和视觉克制之间找到平衡。
3. **纯前端可行性**：对比 App 中大量使用云同步、社区功能，这些不是 v2.0 的优先目标。v2.0 专注纯前端、离线可用的核心阅读体验。

## 9. 结论与建议

### 9.1 禅意设计语言定义

般若佛经阅读器的视觉设计语言可概括为：

> **"以宣纸与墨色为基调，以留白为呼吸，以赭石为点缀，以克制为准则。"**

具体落地标准：
1. **色彩**：全暖色调，非纯黑非纯白，主色赭石 `#A0522D`，语义色低饱和
2. **字体**：宋体为正文，楷体辅助，无衬线体用于 UI，梵文/藏文按需加载
3. **间距**：4px 基准系统，充足的留白创造呼吸感
4. **动画**：200-300ms ease-out，禁止弹跳和装饰性动画
5. **图标**：线性 SVG 图标，1.5-2px 线条，圆角端点，不用 Emoji
6. **圆角**：8-12px 柔和圆角，无锐利边缘
7. **阴影**：极淡（opacity 0.06），仅用于卡片层级区分

### 9.2 设计规范清单

| 规范 | 值 | 说明 |
|------|-----|------|
| 页面背景 | 宣纸白 `#FAF8F3` | 日间 |
| 卡片背景 | 纯白 `#FFFFFF` | 日间，比背景略亮 |
| 正文文字 | 墨色 `#2C2C2C` | 非纯黑 |
| 主色/可点击 | 赭石 `#A0522D` | 中国传统色 |
| 正文行高 | 1.8 | 中文最佳可读性 |
| 正文默认字号 | 17px | 日常诵读 |
| 页面水平边距 | 16px（手机）/ 24px（平板）/ 48px（PC） | 响应式 |
| 圆角 | 8px / 12px | 两级圆角 |
| 标准动画时长 | 250ms ease-out | 克制过渡 |
| 图标线条宽度 | 1.5px（移动端）/ 2px（PC） | 线性描边 |

## 10. 对 v2.1 方案的影响

本设计语言对 v2.1（阅读页面实现）及后续版本的具体影响：

1. **CSS 变量体系重构**：需要从 v1.0 的 `--primary-color: #FF6B35` 全面迁移到新的禅意色板 `--zen-accent: #A0522D`，建立完整的 `zen-*` 前缀变量体系

2. **Emoji 图标替换**：v1.0 中大量使用 Emoji 作为图标（`📖`、`📚`、`🔍`、`⚙️`），v2.1 需要全部替换为 Lucide Icons 的 SVG 线性图标

3. **主题切换机制升级**：从 v1.0 的 `.dark-mode` class 切换升级为 `[data-theme]` 属性切换，支持三种主题（day / dark / eye-care），主题切换时背景色使用 400ms 渐变过渡

4. **圆角系统统一**：v1.0 的圆角为 8/12/16/24px 四级，v2.0 精简为 8px（小组件）和 12px（卡片）两级，去掉 16px 和 24px

5. **阴影系统弱化**：v1.0 的阴影 `0 2px 8px rgba(0,0,0,0.08)` 偏重，v2.0 改为 `0 1px 4px rgba(0,0,0,0.06)`，更轻盈

6. **按钮样式调整**：v1.0 的按钮使用 `#FF6B35` 填充色，v2.0 改为赭石色 `#A0522D`，次要按钮改为描边风格（outline）而非填充

7. **字体栈更新**：v1.0 正文字体使用 Source Han Sans CN（黑体），v2.0 改为 Noto Serif SC（宋体）作为正文首选

8. **Vant 4 组件主题定制**：需要覆盖 Vant 4 的默认主题色，通过 CSS 变量或 Vant 的 `ConfigProvider` 将 Vant 的 `--van-primary-color` 从默认蓝/橙色改为赭石色 `#A0522D`，同时将 Vant 组件的圆角统一为 8px

9. **术语高亮样式**：v1.0 的 `--highlight-bg: #FFF3CD` 保留，但术语文字色从默认黑色改为 `#8B4513`（赭石深），夜间模式改为 `#C8956C`

10. **动画规范收敛**：v1.0 使用了 `0.3s ease` 作为标准动画，v2.0 改为 `0.25s ease-out`，且需要消除所有弹跳和脉冲效果
