# 书架页面设计 分析报告

> 任务编号：T-16
> 完成日期：2026-05-02
> 基于：docs/PROJECT_V2_PLAN.md

## 1. 背景与目标

佛教经文阅读器 v2.0 需要一个书架页面，用于管理用户的经书和词典资源。当前 v1.0 版本中经书数据硬编码在 JS 中，无法动态扩展；v2.0 将经书改为动态加载、按需取用，因此需要设计一个高效的书架管理界面。

**设计目标**：
- 展示用户拥有的所有经书和词典
- 支持快速定位和选择要阅读的经书
- 提供排序、筛选、分组等管理功能
- 符合佛教阅读器"简单、专注、不打扰"的核心理念
- 适配 H5 Web 的 PC/平板/手机三端响应式布局

## 2. 同类 App 对比

| App | 布局 | 封面 | 排序 | 分组 | 特点 |
|-----|------|------|------|------|------|
| 微信读书 | 网格为主，支持列表切换 | 真实封面，无封面时生成默认封面（渐变色+书名） | 最近阅读、书架置顶、自定义排序 | 书架分组（按小说/文学/历史等分类）、私密书架 | 书籍置顶功能、私密阅读模式、阅读进度可视化、社交共读 |
| Kindle | 网格布局（封面墙） | 真实封面为主，本地导入无封面时显示默认灰色封面 | 最近阅读、标题字母序、作者 | Collections（收藏夹），支持按类型/作者/阅读状态分组 | Whispersync 多端同步、X-Ray 辅助工具、阅读进度同步、笔记管理 |
| Apple Books | 网格布局（大封面） | 高质量真实封面，无封面时自动生成渐变色封面 | 最近添加、标题、作者 | 藏书功能：欲读清单、已读完、自定义精选集 | 全屏阅读模式、阅读目标追踪、跨设备 iCloud 同步、有声书集成 |

**关键发现**：
1. **布局共识**：三款主流应用均以**网格布局**为默认视图，封面是书籍识别的核心视觉元素
2. **封面策略**：均支持真实封面 + 无封面时自动生成默认封面（渐变色 + 书名首字母/全文）
3. **排序逻辑**：最近阅读/最近添加是最高频的排序方式，其次是标题字母序
4. **分组能力**：均提供某种形式的分类/收藏夹功能，支持用户自定义分组

## 3. 布局设计

### 网格 vs 列表对比

| 维度 | 网格布局 | 列表布局 |
|------|---------|---------|
| 视觉识别 | 强，封面是快速定位的关键 | 弱，依赖文字信息 |
| 信息密度 | 低，一屏展示书籍数量有限 | 高，可展示更多元数据 |
| 适用场景 | 书籍较少（<50本），快速选择 | 书籍较多（>50本），精确查找 |
| 移动端适配 | 2-3列自适应 | 单列，垂直滚动 |
| 经书适用性 | 适合，经书封面有辨识度 | 适合长列表检索 |

### 推荐方案

**默认网格布局 + 可选列表切换**：

- **桌面端（PC）**：4-5 列网格，每本书显示封面 + 标题 + 阅读进度
- **平板端**：3 列网格
- **手机端**：2 列网格
- **视图切换**：右上角提供网格/列表视图切换按钮
- **列表视图**：显示封面（缩略）+ 标题 + 作者/来源 + 阅读进度 + 最后阅读时间

**理由**：佛教经书数量通常不会太多（几十到上百部），网格布局更符合"快速选择要读的经书"的使用场景。同时保留列表视图作为备选，满足大量经书用户的精确查找需求。

## 4. 封面设计

### 自动生成 vs 用户上传

| 方案 | 优点 | 缺点 | 适用性 |
|------|------|------|--------|
| **用户上传** | 个性化，还原真实经书封面 | 用户可能不提供，增加操作负担 | 适合有封面资源的经书 |
| **自动生成** | 统一美观，零用户操作 | 可能缺乏个性化 | 适合无封面资源的经书 |

### 推荐方案

**混合策略：优先真实封面，无封面时自动生成**：

1. **MDX 词典**：提取内置封面（如有），否则自动生成
2. **上传的经书**：解析元数据中的封面，无则自动生成
3. **自动生成规则**：
   - 使用渐变色背景（佛教主题色调：金色、深红、藏青、墨绿）
   - 中央显示经书标题（竖排或横排，书法字体）
   - 底部可选显示经文首句或心经短句作为装饰
   - 根据经书分类自动选择配色方案

**配色方案建议**：
| 分类 | 主色 | 辅色 | 适用经书 |
|------|------|------|---------|
| 般若类 | 深红 (#8B0000) | 金色 (#FFD700) | 心经、金刚经 |
| 净土类 | 金色 (#DAA520) | 橙红 (#FF6347) | 阿弥陀经、无量寿经 |
| 禅宗类 | 藏青 (#191970) | 银灰 (#C0C0C0) | 六祖坛经、传心法要 |
| 密宗类 | 深紫 (#4B0082) | 金色 (#FFD700) | 大悲咒、楞严咒 |
| 通用类 | 墨绿 (#2F4F4F) | 米白 (#F5F5DC) | 其他经书 |

## 5. 排序和筛选

### 排序规则

| 排序方式 | 说明 | 优先级 |
|---------|------|--------|
| **最近阅读** | 按最后阅读时间倒序 | 默认 |
| **最近添加** | 按添加到书架的时间倒序 | 常用 |
| **标题字母序** | 按经书标题拼音/笔画排序 | 常用 |
| **阅读进度** | 按完成百分比排序 | 可选 |

### 筛选条件

| 筛选项 | 说明 |
|--------|------|
| **资源类型** | 经书 / 词典 |
| **阅读状态** | 未开始 / 阅读中 / 已完成 |
| **经书分类** | 般若 / 净土 / 禅宗 / 密宗 / 通用 |
| **收藏状态** | 已收藏 / 未收藏 |

### 交互设计

- 排序：顶部下拉菜单选择排序方式
- 筛选：顶部标签栏或侧边栏（PC端）显示筛选项，点击切换
- 搜索：顶部搜索框，支持按标题模糊搜索

## 6. 书架分组

### 分组功能设计

参考微信读书和 Apple Books 的分组经验，提供以下分组能力：

**系统预置分组**：
| 分组名 | 说明 | 自动/手动 |
|--------|------|----------|
| 最近阅读 | 最近 7 天内阅读过的经书 | 自动 |
| 阅读中 | 有阅读进度但未完成的经书 | 自动 |
| 已完成 | 阅读进度 100% 的经书 | 自动 |
| 全部 | 所有资源 | 自动 |

**用户自定义分组**：
- 支持创建自定义分组（如"早晚课诵"、"周末修学"、"研究参考"）
- 同一本经书可以加入多个分组
- 支持拖拽或长按添加到分组
- 分组支持重命名、删除、排序

**分组交互**：
- 桌面端：左侧边栏显示分组列表
- 平板端：左侧可折叠边栏
- 手机端：顶部横向滚动的分组标签

## 7. 结论与建议

### 书架页面方案总结

| 决策项 | 结论 |
|--------|------|
| **默认布局** | 网格布局，响应式列数（PC 4-5列、平板 3列、手机 2列） |
| **视图切换** | 支持网格/列表视图切换 |
| **封面策略** | 混合策略：优先真实封面，无封面时按分类自动生成渐变色封面 |
| **默认排序** | 最近阅读 |
| **筛选项** | 资源类型、阅读状态、经书分类、搜索 |
| **分组功能** | 系统预置（最近阅读/阅读中/已完成）+ 用户自定义分组 |
| **交互风格** | 保持禅意极简风格，避免过度装饰 |

### 具体实现建议

1. **组件结构**：
   ```
   BookshelfPage
   ├── SearchBar          # 搜索框
   ├── FilterBar          # 排序和筛选控件
   ├── GroupTabs          # 分组标签栏（移动端）
   ├── BookGrid           # 网格视图容器
   │   └── BookCard       # 单本书卡片
   └── BookList           # 列表视图容器
       └── BookListItem   # 单本书列表项
   ```

2. **BookCard 组件**：
   - 封面图（16:9 或 3:4 比例）
   - 标题（最多 2 行，超出省略）
   - 阅读进度条（仅在阅读中时显示）
   - 长按/右键菜单：添加到分组、删除、查看详情

3. **空状态处理**：
   - 书架为空时，显示引导添加经书的插画和按钮
   - 分组为空时，提示"该分组暂无经书"

4. **性能优化**：
   - 封面图片懒加载
   - 虚拟滚动支持大量书籍场景
   - 封面自动生成结果缓存到 IndexedDB

## 8. 对 v2.1 方案的影响

本分析结果对 v2.1 方案的具体影响如下：

| 影响项 | 说明 | 对应 v2.0 计划章节 |
|--------|------|-------------------|
| **新增 Bookshelf 页面** | v2.0 计划中未明确书架页面设计，需补充 pages/Bookshelf.vue 及相关组件 | 第四章 页面设计 |
